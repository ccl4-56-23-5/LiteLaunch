# 规则功能与兼容范围

依据 [ReNamer规则文档](https://www.den4b.com/docs/books/renamer/chapter/rules) 独立实现。18类规则都可加入、禁用、排序、编辑和保存，另有元数据模板入口。

| 规则 | 本插件参数与行为 |
|---|---|
| Insert 插入 | 开头、末尾、位置、定位文字前后、替换名称；从右计数；元数据插入 |
| Delete 删除 | 位置或分隔符起始；数量、结束分隔符或末尾；保留分隔符；从右删除；清空 |
| Remove 移除 | 多项文本、通配符、大小写、完整单词、首次/末次/全部 |
| Replace 替换 | 多项一一替换、共同替换项、通配符、大小写、完整单词、匹配次数、元数据 |
| Rearrange 重排 | 分隔符列表、顺序分隔符、位置拆分；左右方向；$0、$1、$-1分段；元数据 |
| Extension 扩展名 | 设置、移除、按内容检测；文件夹不按扩展名拆分 |
| Strip 剥离 | 字符、英语、数字、符号、括号、Unicode范围；反选；首部/尾部/全部 |
| Case 大小写 | 大写、小写、标题、首字母、句首、反转、保留；强制片段大小写；扩展名大小写 |
| Serialize 序列化 | 任意精度整数、负步长、补零、重复；按数量/目录/名称重置；十进制、英语、罗马、音符、中文、自定义字母表/数制；前后缀和位置 |
| CleanUp 清理 | 嵌套括号、分隔符转空格、数字间分隔保留、空白、表情、组合标记、驼峰、SharePoint字符 |
| Translit 转写 | 系统ICU内置Unicode方案；汉字转拉丁、繁简、希腊/西里尔等；自定义映射、反向、大小写 |
| ReformatDate 日期重排 | 多个输入格式、输出格式、12个月份名称、完整匹配、年/月/日/时/分/秒/毫秒调整 |
| PascalScript 脚本 | 实际Pascal Script语言、变量/循环/过程/类；编译检查；Unicode、日期、元数据、正则、文件和外部程序接口；每项目2秒 |
| RegEx 正则 | .NET正则、分组替换、大小写、多行/单行、完整词、首次/末次/全部、元数据 |
| UserInput 名称列表 | 文本、文件、剪贴板；UTF-8/UTF-16/GB18030；不足行保留原名 |
| Randomize 随机序列 | 数字、英语、自定义字符；长度、可复现种子、字符空间允许时不重复、插入方式 |
| Mapping 映射 | 两列CSV，支持引号和逗号/分号/制表符；文本/文件/剪贴板；表头、路径、原名匹配；捕获当前预览 |
| Padding 填充 | 数字补零、移除前导零、文本填充、左右方向、目标长度 |

## 元数据

字段目录覆盖文件信息、校验值、图片、EXIF/IPTC、音频ID3/FLAC/WMA、视频、文档/PDF、邮件、字体、种子、APK、程序版本及杂项。支持自定义ExifTool字段和Windows `System.*` 属性。字段格式为 `:EXIF_Model:`；旧 `{name}`、`{num}`、`{parent}`、`{taken:yyyyMMdd}` 等模板继续可用。字段缺失可选停止、空值或替代文字，非法名称字符默认转下划线。

读取由内置ExifTool、结构化文件读取器与Windows属性系统提供，字段取决于真实文件内容和格式，不保证每个文件都有每个字段。APK支持二进制AndroidManifest和普通资源字符串；复杂资源引用未声明全覆盖。转写方案依赖Windows所带ICU；系统不提供该方案时提示改用自定义映射。

## 脚本与原版差异

Pascal语言使用RemObjects原引擎；本插件宿主函数是独立实现，不宣称原版数百个宿主接口逐个完全等价。支持的宿主函数以 `pascal_worker.pas` 和 `pascal_strings.inc` 的注册声明为准，常用的Unicode、数值、日期、元数据、正则接口均可使用。`FileName` 为当前处理的名称；`FilePath` 为原始完整路径；`Counter`、`FileIndex` 从1开始，`FileCount` 为列表总数。标准Pascal变量在本次批量处理的各行间保留，下次预览重新初始化。

文件写入和外部程序调用默认不注册，须显式打开规则中的选项。`ExecConsoleApp(FileName, Parameters): WideString` 是本插件的简化接口，返回标准输出，与ReNamer的同名接口签名不同。每项目限时2秒，整个脚本批次限时110秒；编译检查不执行语句。名称行、JSON、外部文本均有大小上限。原版ReNamer二进制预设没有直接导入器；本插件1.0.1的预设和旧记忆兼容。

正则采用.NET语法，与ReNamer正则方言存在差异；分组替换使用 `$1`、`${name}`。这里只读提取元数据，不提供内部标签编辑。
