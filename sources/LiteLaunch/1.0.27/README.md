# LiteLaunch 1.0.27 · 安装退出修复

本版修复覆盖安装时无法关闭正在运行的轻启，保留1.0.26的GitHub安装包更新修订。主程序为安装版，插件独立更新。

运行LiteLaunch-Setup-1.0.27-x64.exe。确认安装目录后点击安装，向导会询问是否正常退出旧轻启；请先完成或关闭应用编辑窗口，再选择“是”。安装器核对运行文件与目标目录一致，等待进程真正结束后才覆盖。若正在编辑、启动未完成或无响应，会暂停并说明原因；完成当前操作或从托盘选择“退出轻启”后重试。

窗口右上角关闭按钮只收起面板，不代表退出；从托盘菜单选择“退出轻启”才会结束程序。安装器不会按进程名强杀，也不会关闭另一目录的同名程序或独立插件。

安装完成可按向导选项启动轻启。右键菜单中的GitHub更新沿用正式Setup附件识别、产品/版本/大小/SHA-256校验及可见安装向导。

旧更新组件若提示“发布中缺少唯一的LiteLaunch.exe”，需手动运行本版Setup迁移一次。批量重命名1.0.0、鼠标指针1.0.1继续使用原已发布文件及v1.0.25插件目录，已有插件无需重装。用户配置、指针恢复记录、重命名历史保留。

正式发布状态以GitHub项目页面为准。自动检查使用隔离进程验证退出协议及安装包数据，不替代真实安装和人工测试。
