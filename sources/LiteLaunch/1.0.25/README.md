# LiteLaunch1.0.25 · 鼠标指针插件1.0.1

本版修复鼠标指针切换报错，补上真实缩略图、17类指针预览、ANI动画和悬停试用，并把窗口统一为与重命名插件相同的卡片、字体、主题色及按钮样式。主程序保持四个可配置插件槽，软件区首格为使用系统图标的控制面板。仅交付安装版。

## 安装与更新

1. 关闭旧鼠标指针插件窗口。
2. 将LiteLaunch-Setup-1.0.25-x64.exe与LiteLaunch-Plugin-CursorSwitcher-1.0.1-x64.exe放在同一文件夹，运行Setup覆盖安装。
3. 点击鼠标指针插件槽，会校验并把已安装1.0.0升级到1.0.1，再打开新版。也可在插件管理中选中鼠标指针→本地安装→选择本版EXE。

插件不捆绑入主安装包。只收到Setup时会显示明确的插件安装入口；批量重命名插件为可选独立组件，已有1.0.0版本无需因本次指针修改重装。所有插件在管理器内按各自独立版本更新，指针1.0.1最低兼容主程序1.0.24。旧版本的插件界面应先关闭后再启动新版。

## 指针预览与切换

左侧每套后装方案显示真实缩略图和当前状态；右侧显示各类指针，可点选放大、播放ANI动画，并通过鼠标悬停试用。预览只改变预览区域内的指针，不写系统方案。Windows自带方案仍被过滤，未分发任何第三方指针包。

点击“应用此方案”才会写入当前用户指针设置并刷新系统。“恢复上一套”延用原来的previous-state.json，切换前备份、失败时回写原值。现有指针包、原恢复记录、LiteLaunch应用列表与重命名历史均保留。

## 根因和验证

旧版使用SPI_SETCURSORS时传入SPIF_UPDATEINIFILE|SPIF_SENDCHANGE（3），在本机Windows上返回false。相同环境下参数0和2返回true。本版已持久化注册表路径，因此改用SPIF_SENDCHANGE（2），并补充错误码记录；这是本机复现的兼容性修复，并不声称所有Windows系统都拒绝参数3。

已完成真实切换：17类路径读回匹配、系统实际加载的箭头像素改变；随后原始注册值、类型和原箭头像素完全恢复。原previous-state.json摘要未变化。另有18项指针引擎、35项真实图像/ANI/界面/按钮/布局检查，及22项插件管理与完整启动链路检查。重命名代码未改，沿用1.0.24的27项流水线和28项表单验证。
