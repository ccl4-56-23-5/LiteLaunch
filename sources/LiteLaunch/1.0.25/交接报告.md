# LiteLaunch1.0.25维护交接（2026-10-22）

## 本次实现

- 插件cursor-switcher从1.0.0升至1.0.1，最低主程序版本1.0.24。batch-renamer维持1.0.0，规则、事务、存储和窗口源码未改。
- CursorSwitcher.cs：Engine.Reload显式调用SystemParametersInfoW，使用SPI_SETCURSORS/0/null/SPIF_SENDCHANGE，避免旧的UPDATEINIFILE组合在本机失败。保留17个角色和2个方案字段的捕获、校验、备份与回退；失败记录系统错误码。
- CursorUi.cs：共用LiteLaunch调色、圆角和字号；读取Panel/Theme与ScalePercent并适配DPI/屏幕。方案列表真实缩略图，17角色图像，RIFF/ANI元数据和帧序列/速率，DrawIconEx原生动画，预览区域WM_SETCURSOR局部试用。所有预览句柄、图片、定时器在切换方案或关闭时释放。
- manager.ps1：Resolve-PluginForLaunch在已安装版本低于目录版本时，查找并校验相邻新版包，更新激活记录；不再因发现旧installed.json而直接启动旧程序。没有新版包则明确提示更新。沿用1.0.24的正常窗口显示、各插件独立管理窗口、会话日志及.NET SHA-256。
- build-plugins.ps1：独立编译新增CursorUi.cs；版本由plugins/releases.json注入，最终目录含实际附件摘要，主程序嵌入同一目录。

## 本次验证

qa/run-cursor.ps1：18项内存存储引擎检查；35项真实本机指针图像、ANI像素变化、UI应用/恢复按钮、三种尺寸布局与实际同方案刷新检查。
qa/CursorLiveTest.cs：使用临时备份，真实切换到另一已安装自定义方案，验证17字段读回和加载的系统箭头像素改变，然后恢复原19字段和值类型以及原箭头像素。真实previous-state.json未用作测试备份，保留其原摘要。
既有independent-update-verification.json记录了隔离目录内实际1.0.0文件更新为实际1.0.1、主程序1.0.24摘要不变及另一插件目录项保留。可重复的qa/test-independent-update.ps1改用当前源码生成1.0.0协议测试夹具，避免依赖已归档旧版本；该夹具结果单独记录。在线附件验证见本次发布记录。
qa/run-plugin-launch.ps1：保留5项生产C调用→Windows PowerShell5.1→原生重命名窗口的完整链路。
qa/test-plugins.ps1：22项目录、摘要、独立版本、路径约束、损坏修复及本地包发现检查。
重命名规则与表单模块沿用1.0.24逐字节相同的源码与既有27/28项记录；不用本次新增指针测试冒充重命名复测。
