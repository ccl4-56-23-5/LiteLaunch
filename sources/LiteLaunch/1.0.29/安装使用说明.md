# LiteLaunch 1.0.29

在基座面板上右键已配置的插件，选择“检查插件更新（GitHub）”，即可检查并更新该插件，无需重装或重启基座。更新前校验官方发布的大小、SHA-256、产品名和版本号；下载或校验失败时保留旧版，禁止降级。运行中的旧插件窗口继续保留，关闭并重新打开后使用新版。

空插件槽仍可管理和绑定插件；批量重命名原有后悔药、记忆、设置等右键工具保留。插件管理器中的“下载 / 更新”也复用同一套更新逻辑。

主程序固定从 ccl4-56-23-5/LiteLaunch 检查更新，主程序更新仍使用可见的安装向导。批量重命名插件为1.0.1，鼠标指针插件为1.0.1，原始插件二进制保持不变。

编译验证后按用户授权直接安装并上传。源码、标签和发布附件完成远端核验后，本地按项目只保留最新版源码；用户配置、已登记基线和未提交改动继续保护。
从安装包覆盖安装可保留现有配置与启动选项。插件数据与重命名撤销历史不会随更新清除。
