# LiteLaunch 1.0.32 测试版 · 连续缩放与小字号清晰度

设置菜单中的“页面大小…”支持 50%–150% 连续滑块调节，并可输入精确到 0.01% 的比例。拖动或输入时实时预览；“应用”保存，“取消”、Esc 或关闭窗口恢复进入前的比例、面板位置和滚动位置。“恢复100%”可快速预览默认大小。

页面大小对话框和设置菜单按系统 DPI 保持正常操作尺寸，不随主面板缩到 50%。应用名称文字直接按最终设备像素绘制并对齐像素，使用 ClearType 网格拟合，标签最小 10 像素；标题最小 11 像素，辅助及底栏最小 9 像素。小尺寸下不足两行的标签改为单行省略，悬停或键盘选中应用时底栏显示对应名称，仍以底栏可用宽度省略。50% 界面可用空间有限，不宣称与 100% 具有相同可读性。

本版为测试发行；稳定版 1.0.31 保留。基座与插件继续独立维护，本次不重建插件，也不降低用户已装插件版本。源仓库保留批量重命名 1.0.6 的独立工程；本体离线目录仍沿用原始批量重命名 1.0.4 和鼠标指针 1.0.1 的包身份，在线目录继续发现较新独立插件。
