# LiteLaunch 1.0.32 维护说明

本次修改是 50%–150% 连续缩放及小比例文字绘制。1.0.32 按测试发行发布，保留 1.0.31 稳定入口；本次不改变独立插件的版本和发布目录。用户人工验收尚未进行，自动验证与本机安装结果以本版记录为准。

## 缩放数据与交互

`main.c` 使用双精度百分比，配置 `Panel/ScalePercent` 保留两位小数；有效区间为 50–150。加载兼容原整数比例，异常、非有限或超界输入按解析规则处理。面板有效 DPI 为系统 DPI 乘页面比例，绘制/布局避免先取整 DPI 造成比例跳档。

页面大小窗口为独立系统 DPI 对话框。滑块内部范围为 5000–15000，数值除以 100 得到百分比；鼠标拖动连续预览，输入可精确到 0.01%。拖动只预览；“应用”成功保存后提交，保存失败留在窗口；“取消”、Esc 或关闭恢复原比例、位置及滚动状态。对话框和菜单字体、控件尺寸不随面板比例缩小。

## 字体与紧凑布局

`glass.cpp` 的 `pixelText` 把逻辑文字区域转换为最终设备像素并取整边界，在文字绘制时重置几何变换，使用 `TextRenderingHintClearTypeGridFit` 按最终像素尺寸绘字；卡片和装饰仍沿用原逻辑坐标缩放。文字区域背景不透明，不对已经绘制的文字再做缩小采样。

应用标签为 `max(10, round(12.2*scale))` 设备像素，标题至少 11 像素，辅助文字和底栏至少 9 像素。当标签区域容纳不了两行时使用单行省略；悬停或键盘选中应用后，底栏显示该应用名，宽度不足仍省略。不要承诺 50% 与 100% 等同的阅读空间。

## 构建与验证


构建与维护入口为 `sources/LiteLaunch/1.0.32`。Windows 上使用 PowerShell 7、Zig 和 Inno Setup 6，根目录执行 `./build.ps1 -ReusePluginPackages`。先将本体 `plugins/catalog.json` 所列原始插件资产放入解析后的 `output/LiteLaunch/1.0.32`；构建会验证 SHA-256、产品名和版本。

`build-paths.ps1` 自动识别工作区的 `source/LiteLaunch/1.0.32` 布局；缓存写入工作区 `.cache/LiteLaunch/1.0.32`，正式产物写入 `output/LiteLaunch/1.0.32`。独立克隆仓库默认使用仓库内同名目录。可用 `LITELAUNCH_WORKSPACE`、`LITELAUNCH_COMPILER` 和 `LITELAUNCH_INNO_COMPILER` 覆盖环境配置。

主要验证入口为 `qa/run-scale.ps1`、`qa/run-regression.ps1`、`qa/run-plugin-context.ps1`、`qa/run-installer-shutdown.ps1` 和 `qa/verify-update-package.ps1`。安装器保留稳定 AppId 与现有安装目录识别方式；覆盖前正常退出，保留用户配置、插件和启动选项。

编译工具当前优先检测工作区 Zig 0.17.1，保留 Zig 0.15.2 回退与显式环境变量覆盖。安装器仍使用 Inno Setup 6，与现有 32 位退出桥接组件一致。运行时更新器继续由 Windows PowerShell 5.1 执行，相关脚本维持 UTF-8 BOM。

本次检查应覆盖百分比解析/边界/持久化/回退、50/中间/100/150比例下的布局和点击映射、底栏和短标签省略、基座配置/托盘/中键路由，以及安装包资源身份。测试通过、安装通过与用户满意是独立状态。历史交接报告保存原日期和原版本结论，不改写成 1.0.32 验证结果。
