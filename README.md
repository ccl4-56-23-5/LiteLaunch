# LiteLaunch 1.0.28 与批量重命名插件 1.0.1

[主程序安装版](https://github.com/ccl4-56-23-5/LiteLaunch/releases/tag/v1.0.28) · [批量重命名插件 1.0.1](https://github.com/ccl4-56-23-5/LiteLaunch/releases/tag/batch-renamer-v1.0.1)

主程序当前正式版为 1.0.28，插件按需独立更新。批量重命名插件更新为 1.0.1；鼠标指针插件仍为 1.0.1，二进制保持不变。

批量重命名插件提供 EVER 简易处理与规则队列切换，修复参数标签换行裁切，新增清空名称、批量文件夹入口，并将命名预设固定保存在安装目录的 RenamePresets。222 项自动检查通过，人工使用验收尚未记录。

主程序固定从官方仓库检查更新，下载并校验后打开可见的正常安装向导。独立插件发布不更改主程序最新安装版通道。插件管理器点击检查更新后读取包含 1.0.1 的在线目录。

源码与构建入口：主程序位于 sources/LiteLaunch/1.0.28，独立重命名插件位于 sources/LiteLaunchBatchRenamer/1.0.1。第三方许可证保留于对应 vendor 目录。
