# LiteLaunch 1.0.31 · 更新版本显示与界面统一

插件更新与软件更新窗口持续显示当前版本、最新版本，按钮标明“更新到 x.x.x”；检测后可直接查看版本再更新，完成后保留结果版本。

插件右键第一层顶部显示“更新插件…”，无需进入管理窗口。菜单沿用基座的字体、配色和选中样式；插件管理、插件更新及软件更新使用一致的主题色、圆角按钮和版本卡片。

批量重命名插件保持1.0.6，鼠标指针保持1.0.1，复用已发布的原始二进制。插件目录继续指向独立插件发布，插件更新无需重装基座。

批量重命名功能维护使用 sources/LiteLaunchBatchRenamer/1.0.6 独立工程；基座工程保留既有基础验证模块，打包时复用插件交付件。

本版验证包括实际窗口版本标签、点击更新时的目标一致性、右键一级入口、插件热更新、基座回归与安装包资源核对。自动检查、本机安装和用户人工验收分别记录。

重命名插件1.0.6新增规则和简易添加默认在名称末尾插入，保留扩展名时插在扩展名前；已有规则的位置设置继续保留。219项插件自动检查通过，基座保持1.0.31。

重命名插件1.0.6文件预览区新增排序依据和正序倒序，支持文件名、拍摄时间、修改/创建/访问时间、大小、扩展名及原始顺序；编号按排序重算，手工名称与文件一起移动，支持排序撤销。250项插件自动检查通过，基座保持1.0.31。
